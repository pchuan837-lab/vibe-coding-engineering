# 《Vibe Coding 工程化》手册

一套写给**有基础的准开发者 + 接手项目的 AI** 的工程化实战手册，覆盖需求澄清、方案设计、Bug 修复、重构四条主线的完整方法论与可复用提示词。

> 在线阅读：**https://pchuan837-lab.github.io/vibe-coding-engineering/**（GitHub Pages 托管，明暗自适 + 四档色温）

---

## 这是什么

- **不是**一篇泛泛的"AI 写代码技巧"文章，而是一套可落地、可验收的工程化流程。
- 配套一个真实的 **电商退款 Go 项目**（`vibe-coding-refund-shop`）：B1 / B2 / B3 三条轨道全部在该项目上实操，边学边改，全程可见证据。
- 每个章节都带**验收清单**，读完就能照着执行、对照检查自己有没有做到位。

## 如何阅读

**在线读**（推荐）：打开上面的 Pages 网址，左侧为大纲导航、右侧为当前章节目录、支持折叠、明暗与色温切换。

**本地运行**：这是一个纯静态站点（HTML/CSS/JS），克隆后直接打开 `index.html` 即可，无需构建：

```bash
git clone https://github.com/pchuan837-lab/vibe-coding-engineering.git
cd vibe-coding-engineering
open index.html        # 或直接在浏览器双击打开
```
