这本手册

《Vibe Coding 工程化：从需求到可靠交付的通用流程》是一套面向开发者与准开发者的实操手册。它不教语法，而是带你在有限的时间里，稳定地产出可验收、可复用、可协作的中间产物。三条轨道——B1 通用需求（新功能）、B2 Bug 修复、B3 重构——共享同一套判断力内核，各有专属打法；共享单元负责贯穿全程的测试回归、文档交付与工具链。

勘误与 Bug 反馈

如果你发现正文错误、步骤走不通、命令失效，欢迎来纠错。反馈时请尽量带上：

  • 所在章节（如 B1-①、S-B）与页面地址；
  • 你做了什么、期望什么、实际出现了什么；
  • 环境信息（操作系统 / 语言模型 / 终端报错原文，如有）。

提交入口 —— 在 GitHub 上提交 issue。重要勘误会进入下方的更新记录；紧急阻断类问题优先处理。
